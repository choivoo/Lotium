# Concept B — CORE / NEUTRAL (메인 중심안)

| 항목 | 내용 |
|---|---|
| 전체 인상 | 세련되고 중성적인 테크웨어 정령. 6.5등신, 슬림. 장기 메인 모델로 질리지 않는 균형형. |
| 얼굴 | 부드러운 V라인, 차분하지만 호기심 있는 표정. 블러시 25%. |
| 눈 | 중간 크기(22~24%), 눈꼬리 수평~살짝 올라감. |
| 눈동자 | 금빛/오렌지 방사 그라데이션, 둥근 사각 동공 + 얇은 시안 링, 하이라이트 2(흰+시안). |
| 눈썹 | 가늘고 곧은 눈썹, 앞머리 사이로 보임. |
| 헤어 | 중단발, 전류처럼 끝 10%가 가볍게 꺾임. 회로형 앤젤링. |
| 앞머리 | 비대칭 옆가르마(왼쪽 7:3), 가닥 6, 눈 사이 가닥 1. |
| 옆머리 | 턱선까지, 끝이 바깥으로 튐. 오른쪽에 시안 이너 브리지. |
| 뒷머리 | 목덜미 덮는 2단 레이어, 끝 바깥 꺾임. |
| ahoge/잔머리 | S자 ahoge 1, 관자놀이 잔머리 2. |
| 귀 | 반쯤 노출, 왼쪽 귀에 작은 이어커프. |
| 헤드셋 | 검정 슬림 헤드셋, 이어컵 시안 링, 왼쪽 붐 마이크. |
| 목 | 하이넥 사이로 약간, 검정 초커형 케이블 링. |
| 이너 | 검정 하이넥 핏 이너, 가슴에 코어 소켓. |
| 재킷 | 크림 쉘 오버사이즈, 오렌지 어깨·옆 패널, 앞 짧고 뒤 긴 밑단, 접힌 후드. |
| 소매 | 드롭 숄더, 손목에서 넓어짐, 끝 시안 라인. |
| 장갑/손 장식 | 검정 핑거리스 한쪽(오른손), 손등에 작은 LED. |
| 하의 | 검정 테이퍼드 카고 팬츠, 오렌지 스트랩 1. |
| 다리 | 곧고 가늘게. |
| 신발 | 테크 스니커(크림 베이스, 검정 솔, 오렌지 끈). |
| 가슴 코어 | 둥근 모서리 마름모, 시안 발광, 지퍼 위. |
| 케이블/전기띠 | 허리 뒤 포트 → 케이블 1가닥 발목까지, 시안 전기띠 나선 1~2. |
| 드론/정령 | 오른쪽 어깨 위 캡슐 드론 "핍" 1기 + 머리 뒤 3분할 링. |
| UI | 좌우 소형 홀로 패널(배터리/신호). |
| 컬러 분배 | 크림 40 / 오렌지 30 / 검정 20 / 시안 10 |
| 발광 위치 | 코어, 소매 끝, 헤드셋 링, 케이블 전기띠, 머리 이너 라인, 링. |
| Live2D 움직임 | 앞/옆/뒷머리 다층, ahoge, 재킷 밑단, 후드, 케이블, 드론, 링, 소매. |
| 토글 | 헤드셋, 후드, 드론, 링, UI, 장갑, 발광 강도. |
| 장점 | 중성성·세련됨·확장성 최상. 폼 장식 얹기 쉬움. |
| 단점 | 첫인상 친근함이 A보다 약함, 기술 기믹이 C보다 약함. |
