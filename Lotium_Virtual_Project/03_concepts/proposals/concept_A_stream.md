# Concept A — STREAM / CUTE

| 항목 | 내용 |
|---|---|
| 전체 인상 | 방송 첫인상이 가장 친근한 안. 둥근 형태 언어, 머리 볼륨 크고 등신 약 6등신. "화면 속 귀여운 도우미". |
| 얼굴 | 둥근 볼, 턱끝 부드러움. 기본 표정 입꼬리 올라감, 블러시 35%. |
| 눈 | 크고 둥근 눈(얼굴 폭 25%), 처진 눈꼬리 약간. |
| 눈동자 | 오렌지→앰버 그라데이션, 하트 아님·둥근 동공, 하이라이트 3개(큰 흰+작은 흰+시안). |
| 눈썹 | 짧고 둥근 눈썹, 앞머리에 반쯤 가려짐. |
| 헤어 | 둥근 버섯형 볼륨 + 끝만 살짝 튐. 오렌지 비중 높음. |
| 앞머리 | 눈썹까지 오는 풀뱅, 가닥 5개, 가운데 가르마 없음. |
| 옆머리 | 볼을 감싸는 짧은 가닥, 끝 바깥으로 말림. |
| 뒷머리 | 목덜미 위 짧은 단발, 1단. |
| ahoge/잔머리 | 큰 ahoge 1개(하트 아님, 둥근 루프), 잔머리 2. |
| 귀 | 머리에 거의 가려짐, 귓불만 보임. |
| 헤드셋 | 크림색 큰 이어머프형, 고양이귀 아닌 둥근 안테나 2개. |
| 목 | 짧게 보임(하이넥 칼라에 가려짐). |
| 이너 | 오렌지 후드티. |
| 재킷 | 크림 오버사이즈 푸퍼 크롭 재킷, 둥근 퀼팅. |
| 소매 | 손 전체를 덮는 긴 소매(소매 끝 시안 라인). |
| 장갑/손 장식 | 없음, 소매로 손가락만 보임. |
| 하의 | 검정 반바지 + 크림 레깅스 라인. |
| 다리 | 짧고 가늘게, 무릎 양말(오렌지 줄). |
| 신발 | 둥근 앞코 하이탑 스니커(크림/오렌지). |
| 가슴 코어 | 후드 끈 끝에 달린 작은 원형 코어 2개. |
| 케이블/전기띠 | 짧은 꼬리 케이블, 끝에 둥근 플러그. |
| 드론/정령 | 둥근 캡슐 드론 2기(양 어깨). |
| UI | 말풍선형 채팅 UI, 하트/별 이모트 패널. |
| 컬러 분배 | 오렌지 40 / 크림 40 / 검정 12 / 시안 8 |
| 발광 위치 | 소매 끝, 코어, 드론 눈. |
| Live2D 움직임 | ahoge, 후드 끈, 소매, 드론 2기, 꼬리. |
| 토글 | 후드, 드론, 채팅 UI, 볼 블러시 강. |
| 장점 | 친근·귀여움 최고, 쇼츠/썸네일에 강함. |
| 단점 | 어려 보이고 중성보다 '귀여운 아이' 쪽. 장기 메인으로는 정체성이 약함. 드론 2기로 리깅 부담, 원형 코어가 몬스터볼 연상 위험. |
