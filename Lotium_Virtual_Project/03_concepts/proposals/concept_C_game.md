# Concept C — GAME / TECH

| 항목 | 내용 |
|---|---|
| 전체 인상 | 게임 방송용 하이텍 스타일. 시안·검정 비중 증가, 각진 형태, 기능성 기믹 다수. |
| 얼굴 | 약간 날카로운 인상, 자신감 있는 미소. |
| 눈 | 눈꼬리 올라감, 중간 크기. |
| 눈동자 | 오렌지 홍채 + 시안 조준선형 동공 링(십자 없음). |
| 눈썹 | 짙고 각진 눈썹. |
| 헤어 | 뒤로 넘긴 스파이키 숏, 끝 시안 투톤. |
| 앞머리 | 짧게 올린 앞머리, 이마 노출. |
| 옆머리 | 짧게, 헤드셋 아래로 눌림. |
| 뒷머리 | 짧은 층, 목덜미 노출. |
| ahoge/잔머리 | 뾰족한 가닥 2(안테나 느낌). |
| 귀 | 헤드셋에 가려짐. |
| 헤드셋 | 대형 게이밍 헤드셋, 이어컵 RGB 링, 고글형 HUD 바이저. |
| 목 | 넥 게이터(검정). |
| 이너 | 검정 컴프레션 이너 + 시안 회로 라인. |
| 재킷 | 검정/오렌지 경량 봄버, 어깨 패널 LED. |
| 소매 | 슬림, 팔뚝 컨트롤러 버튼형 패치. |
| 장갑/손 장식 | 양손 게이밍 장갑, 손끝 발광. |
| 하의 | 검정 조거 + 허벅지 홀스터형 파우치(무기 아님, 배터리 팩). |
| 다리 | 슬림, 무릎 패드. |
| 신발 | 검정/시안 하이테크 부츠형 스니커. |
| 가슴 코어 | 대형 코어 + 게이지 링. |
| 케이블/전기띠 | 헤드셋과 코어 연결 케이블 + 등 뒤 2가닥. |
| 드론/정령 | 방열판형 드론 + HUD 투사. |
| UI | 대형 HUD, 콤보 카운터, 체력 대신 배터리 바. |
| 컬러 분배 | 검정 35 / 시안 25 / 오렌지 25 / 크림 15 |
| 발광 위치 | 전신 다수(헤드셋, 장갑, 이너 라인, 코어, 신발). |
| Live2D 움직임 | 바이저 개폐, 케이블 2+1, 드론, HUD. |
| 토글 | 바이저, HUD, RGB 모드, 장갑 발광. |
| 장점 | 게임 방송 임팩트, 기술 기믹 풍부. |
| 단점 | 장식 과다로 리깅·가독성 부담, 중성·친근함 약화, 성인/남성적 인상 쪽으로 기울 위험. 크림 비중 낮아 브랜드 배색 이탈. |
