# Concept Merge — 최종안 = B 전체 + A 친근함 + C 기술 요소

## 1. 베이스: B (CORE / NEUTRAL)
체형·등신·재킷 구조·팔레트 비율(크림40/오렌지30/검정20/시안10)·헤어 구조·코어·케이블·드론 1기·링을 그대로 채택.

## 2. A에서 가져오는 것 (친근함)
| 요소 | 적용 방식 |
|---|---|
| 둥근 볼·기본 미소 | B 얼굴에 볼 곡선 +5%, 기본 입꼬리 상향 |
| 하이라이트 풍부한 눈 | 하이라이트 2 → 3 (큰 흰 + 작은 흰 + 시안 점) |
| 손을 반쯤 덮는 소매 | B 벨 소매 길이를 손등 절반까지 |
| 둥근 ahoge | S자 끝의 꺾임을 둥글게 완화 |
| 후드 끈 | 재킷 칼라에서 내려오는 오렌지 끈 2개(물리 파츠) |
| 채팅형 UI 이모트 | 표정 연출용 이모트 패널 토글(하트/물음표/땀/!?) |

## 3. C에서 가져오는 것 (기술 요소)
| 요소 | 적용 방식 |
|---|---|
| HUD 바이저 | 헤드셋에서 내려오는 **반투명 시안 바이저** — 게임폼 토글 전용 |
| 게이지 링 코어 | 코어 둘레 얇은 게이지 링 → 배터리/오버클럭 표시 |
| 배터리 바 UI | UI 패널 중 1개를 배터리 바로(부족 연출용) |
| 손등 LED | 오른손 핑거리스 장갑 LED |
| 시안 이너 라인 | 이너 앞 세로 회로 라인 2줄 |

## 4. 배제
- A: 드론 2기(→1기), 원형 코어(몬스터볼 연상), 푸퍼 퀼팅(주름 과다).
- C: 대형 헤드셋, 스파이키 숏(성인 남성적), 양손 장갑, 무릎 패드, 파우치, 과다 발광.
