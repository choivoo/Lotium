# CR-001: 목·얼굴 이중(double chin/neck) 현상 수정

- 대상: `06_psd_parts/LTM_LIVE2D_MASTER_v001.psd` → **v002**
- 보고: 사용자 태블릿 스크린샷(턱 아래 두 번째 턱선, 살색 기둥, 머리끝 사이 투명 구멍)
- 원인
  1. `Neck` 레이어가 전신 마스터의 목 영역을 잘라 쓰면서 **전신 마스터의 턱까지 포함** → Face Master 턱과 이중 턱
  2. `Face_Base` 측면 확장(14px)이 턱 아래까지 번짐 → 두 번째 얼굴 윤곽
  3. 전신 마스터의 머리끝이 덮던 후드/하이넥 부분이 비어 투명 구멍
  4. `Arm_*_Under` 원형 끝단이 후드 위로 노출, 밝은 안감이 이음새로 비침, Face Master 후드 외곽선이 옆머리 파츠에 섞임
- 조치
  1. `Neck`, `Neck_Back` **새로 작화**(턱 그림자·목 외곽선 포함, Face Master 좌표계로 배치) — 전신 마스터 턱 픽셀 사용 안 함
  2. `Face_Base` 확장을 볼 옆(턱 위)으로만 제한
  3. `Inner_Body` 하이넥 상단 재작화, `Hood_Folded` 목 뒤 안감 재작화(머리카락 색 제거, 평탄 채움+외곽선)
  4. 팔 복원은 어깨 아래로 클립, 안감 어두운 색, Face Master y≥835 후드 픽셀을 헤어에서 제외, 3배 확대 마스크 계단 현상 스무딩
- 검증: PSD v002 재오픈 → 149 레이어, 빈 0 / 중복 0, PSD 자체 합성에서 턱·목 단일 확인
- 상태: 완료
