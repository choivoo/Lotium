# 01. 프로젝트 개요 — 로티움 (Lotium)

## 1.1 목표
- 로토무에서 **영감만 받은** 완전 오리지널 버츄얼 캐릭터 "로티움" 제작.
- 단일 일러스트가 아닌, Live2D 리깅에 바로 투입 가능한 **파츠 분리형 일러스트 + 120레이어 전후 PSD 설계**를 완성.
- 스마트폰에서도 문서/체크리스트/버전 관리가 가능하도록 모든 산출물을 Markdown·CSV 기반으로 저장소에 관리.
- Codex CLI(Claude 연동) 흐름으로 기획 → 프롬프트 → 레퍼런스 → 러프 → 정제 → 파츠 분리 → PSD 정리까지 단계별 실행.

| 구분 | 산출물 | 형식 | 위치 |

## 1.3 사용 목적
- **버츄얼 방송**: VTube Studio 등에서 기본 방송 아바타로 사용.
- **Live2D**: 머리 XY, 몸 XYZ, 호흡, 머리카락/케이블 물리, 표정 전환, 폼 토글.
- **방송**: 잡담/게임/감성/이벤트 방송별 토글 세트 운용.
- **쇼츠**: 세로 화면 대응, 과장 표정·glitch 연출 중심.
- **썸네일**: 표정 단품 추출(활짝 웃음/놀람/오버클럭) 및 이펙트 강조 컷.
- **프로필**: SNS 아이콘용 흉상 컷(기본폼/오버클럭폼 2종).
- **감정 전환**: 14종 표정 + 단축키 매핑으로 실시간 전환.

## 1.5 폼 구성
1. 기본 방송폼 — 표준 아바타, 모든 토글의 기준점
2. 모바일폼 — 경량·세로 화면, 스마트폰 UI 장식
3. 게임폼 — 컨트롤러/HUD 장식, 하이텐션
4. 오버클럭폼 — 시안→화이트 고발광, 머리 스파이크 확장, 경고 UI
