# 02. 캐릭터 컨셉 정리 — 로티움 (Lotium)

## 2.1 기본 정보
| 항목 | 내용 |
|---|---|
| 이름 | 로티움 (Lotium) |
| 종족 | 디지털 전기 정령 (Data-Spark Spirit) |
| 성별 | 무성/중성 — 호칭은 "로티움" 또는 중립 표현 |
| 외견 나이 | 소년형~중성형, 14~17세 인상 |
| 본체 | 형태 없는 전류 데이터 덩어리. 인간형은 방송용 "출력 아바타" |
| 대표 색 | 주황 #FF8A1F / 크림화이트 #F6EFE2 / 검정 #1A1A1F / 시안 전기광 #3FF2FF |

## 2.2 세계관
- 오래된 공유기와 스마트폰 충전 케이블 사이, 과전류 순간에 태어난 데이터 생명체.
- 전자기기 사이를 신호처럼 이동하며, 머무는 기기에 따라 외형과 목소리가 "재출력"된다.
- 방송 화면은 로티움에게 "창문". 시청자와 대화하기 위해 인간형 아바타를 렌더링한다.
- 배터리·신호 세기·발열이 곧 컨디션. 배터리 부족 = 졸림, 과열 = 오버클럭 폭주.

## 2.3 성격
- 호기심 많고 친근함. 새로운 기기·앱·게임에 바로 "접속"해보고 싶어 함.
- 장난기: 화면 UI를 몰래 바꾸거나 알림음을 흉내냄.
- 허당: 신호가 끊기면 말이 버벅이고 glitch가 남.
- 속은 다정함. 시청자를 "접속자"라고 부르며 연결이 끊기는 것을 싫어함.
- 오버클럭 시 자신감 과다·하이텐션, 끝나면 방전되어 축 늘어짐.

## 2.4 말투
- 기본: 가볍고 밝은 반말+존댓말 혼용. "접속 완료~! 오늘도 신호 좋다!"
- 기술 용어를 감정 표현에 섞음: "지금 기분 배터리 100%", "그 말 좀 렉 걸린다?"
- 당황 시 끊김 표현: "자, 잠깐— 버, 버퍼링 중…"
- 오버클럭: 짧고 강한 문장. "출력 최대. 따라와."
- 성별 어미/호칭 편향 없는 중립 어휘 유지.

## 2.5 매력 포인트
1. 인간형 아바타 ↔ 정령 본체라는 이중 정체성
2. 기기 따라 바뀌는 폼 = 방송 콘텐츠 자체가 변신 이벤트
3. 전기띠 꼬리·드론 링 등 움직임이 많은 물리 파츠 → Live2D에서 생동감
4. 감정이 UI/전기광으로 가시화 (배터리 게이지, 경고창, glitch)
5. 중성적 귀여움으로 넓은 시청자층 수용

## 2.6 방송 콘셉트
- "기기 속 정령의 접속 방송" — 방송 시작은 부팅, 종료는 절전 모드 연출.
- 고정 코너: 기기 탐방(리뷰), 게임 접속, 신호 사연(감성), 오버클럭 타임(하이라이트).
- 방송 상태 = 캐릭터 상태: 후원 → 충전, 채팅 폭주 → 과열/오버클럭.

## 2.7 RP 활용 방식
- 채팅 명령어로 폼 체인지 요청 → 토글 전환 (예: "!모바일" → 모바일폼 장식 on).
- 방송 사고(렉/끊김)를 glitch 표정으로 캐릭터 연출화.
- 시청자 = 접속자, 구독 = 페어링, 후원 = 충전 등 용어 체계 통일.
- 쇼츠: "기기 이동 챌린지" — 폰→PC→게임기로 튀어나오는 컷.

## 2.8 보이스체인저와 설정의 연결성
- 로티움의 목소리는 "현재 접속한 기기의 스피커로 합성된 음성"이라는 설정.
- 따라서 방송/기기/폼에 따라 음색이 달라져도 설정상 자연스러움.
  - 기본폼: 중성 톤, 약간 밝게
  - 모바일폼: 가볍고 높은 톤
  - 게임폼: 이펙트 약간, 에너지 톤
  - 오버클럭폼: 저음 레이어+디스토션
- 보이스체인저 불안정/잡음도 "신호 간섭"으로 흡수 가능.

## 2.9 폼 체인지의 설정적 이유
| 폼 | 트리거 | 설정 이유 | 시각 변화 |
|---|---|---|---|
| 기본 방송폼 | 방송 PC 접속 | 가장 안정적인 출력 환경 | 표준 의상/헤드셋 |
| 모바일폼 | 스마트폰으로 이동 | 저전력 최적화 렌더링 | 슬림 장식, 폰 UI 패널, 배터리 아이콘 |
| 게임폼 | 게임기/게임 실행 | 입력 반응 속도 모드 | 컨트롤러 버튼 장식, HUD, 고글 |
| 오버클럭폼 | 과부하/과열/이벤트 | 한계 이상 전류 → 본체 에너지가 새어나옴 | 고발광, 스파이크 확장, 경고 UI, 코어 폭주 |

## 2.10 저작권 안전 원칙 (요약)
- 로토무의 얼굴 구조(둥근 몸체+번개형 돌기+파란 오라 눈 구조), 공식 실루엣, 포켓몬 문양 직복제 금지.
- 공유 요소는 "가전/기기에 깃드는 전기 존재"라는 **추상 아이디어**와 **주황+전기 배색 분위기**까지만.
- 인간형 테크웨어 아바타, 코어·케이블·드론 링 등 독자 모티프를 주 식별 요소로 삼는다.
