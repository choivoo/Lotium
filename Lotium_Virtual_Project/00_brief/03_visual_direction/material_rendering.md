# 03-4. 재질·렌더링 가이드

## 1. 공통
- 캔버스 4000×6000px, 300dpi, sRGB. 채색 레이어는 베이스(Normal) + 그림자(Multiply) + 하이라이트(Screen/Add)로 파츠별 구성.
- Live2D 변형을 고려해 그라데이션은 **파츠 내부에만**, 파츠 경계를 넘는 그라데이션 금지.

## 2. 재질별 스펙
### 천 — 쉘 재킷 (Cream #F6EFE2)
- 그림자1 #D9C9B8 (Multiply 대체 시 #E0D0F0 30%), 그림자2 #B8A89A.
- 주름: 팔꿈치 2, 허리 스트랩 아래 2, 어깨 1. 그 외 없음.
- 오렌지 패널 경계에 스티치 점선(2px, #D95F10).

### 천 — 이너/하의 (Black #1A1A1F)
- 그림자 대신 **하이라이트 기반**: 베이스 #1A1A1F, 밝은면 #2E3346, 림라이트 #3FF2FF 20%.
- 순흑 금지 — 항상 Deep Navy #20263A 반사를 섞음.

### 무광 플라스틱 — 헤드셋·코어 케이스·드론
- 베이스 검정/크림, 그림자 1단, 모서리 하이라이트 1줄(#FFFFFF 70%).
- 이어컵 외곽에 시안 링 발광.

### 금속 — 지퍼, 플러그 핀, 버클
- 은색 #C9CED8, 그림자 #6B7280, 하이라이트 순백 날카롭게. 전체 면적 3% 이하.

### 홀로그램 — UI 패널, 정령 링
- 시안 #3FF2FF 60% + 가산 블렌딩, 가로 스캔라인 2px 간격 15%.
- 테두리만 100%, 내부는 20~40%. 글자는 의미 없는 기호/숫자(실제 브랜드·게임 UI 흉내 금지).

### 발광 — 코어, 발광 라인, 전기띠
- 3층 구조: Core(#EFFFFF) → Color(#3FF2FF) → Glow(가우시안 블러 20~40px, Add, 50%).
- Glow는 반드시 **별도 레이어**(Live2D에서 불투명도 파라미터로 약/중/강 제어).

### 피부
- 매트 셀 2단, 블러시는 에어브러시 1층(별도 레이어). 코끝·볼 하이라이트 작은 점.

### 머리카락
- 베이스 #FF8A1F → 끝 #FFC04D 그라데이션, 그림자1 #D95F10, 그림자2 #A8420A.
- 이너 컬러 시안 브리지 라인, 회로형 앤젤링 하이라이트 #FFF1C9.
- 머리 뒤쪽 레이어는 한 단계 어둡게(깊이감).

## 3. 광원 규칙
- 주광: 좌상단 45°, 따뜻한 흰색.
- 보조광: 코어 기준 시안 반사 — 턱 밑, 재킷 안쪽, 손바닥 안쪽에 20% 이하.
- 오버클럭: 보조광 50%로 증가, 전신 외곽 시안 림라이트 추가.
