# 03-1. 비주얼 아트 디렉션

## 1. 전체 그림체
- 일본 애니메이션풍 **고급 VTuber 일러스트** (Live2D 모델 원화 품질).
- 셀 셰이딩 기반 + 얇은 그라데이션/발광을 더한 "클린 애니 + 테크 글로우" 스타일.
- 정보량 배분: 얼굴 40% / 헤어 25% / 상체 의상 25% / 하체·소품 10%. 방송에서 주로 보이는 가슴 위쪽에 디테일을 집중한다.

## 2. 소년형~중성형 외형 (15~17세 인상)
| 요소 | 방향 | 피할 것 |
|---|---|---|
| 얼굴형 | 부드러운 V라인, 턱끝 약간 둥글게 | 각진 턱, 매우 뾰족한 턱 |
| 눈 크기 | 얼굴 폭의 약 22~24% (중간 크기) | 과도하게 큰 순정 눈, 작고 날카로운 성인 눈 |
| 속눈썹 | 위 속눈썹 굵은 라인 1개 + 짧은 끝 2가닥 | 긴 아래 속눈썹, 풍성한 속눈썹 |
| 입술 | 선 하나, 입술 색 없음 | 립 컬러, 두툼한 입술 |
| 목 | 가늘지만 곧게, 목울대 없음 | 굵은 목·목울대, 지나치게 가는 목 |
| 어깨 | 머리 폭 약 1.6배, 수평 | 넓은 역삼각형, 좁고 처진 어깨 |
| 가슴·허리 | 평평한 상체, 허리 곡선 최소 | 굴곡 강조, 복근·근육 묘사 |
| 골반 | 어깨보다 좁음 | 넓은 골반 |
| 다리 | 곧은 다리, 무릎 표현 간단 | 허벅지 강조, 근육질 종아리 |
| 등신 | 약 6.5등신 | 7.5 이상(성인), 5 이하(SD) |

- 여성적 신호(립, 긴 속눈썹, 굴곡)와 성인 남성 신호(목울대, 근육, 각진 턱, 수염)를 **둘 다** 배제한다.
- 중성성은 "헐렁한 테크웨어 볼륨 + 슬림한 체형 + 짧은~중간 머리"로 만든다.

## 3. 얼굴 디자인
- 인상: 밝고 호기심 많은, 입꼬리가 기본적으로 살짝 올라간 얼굴.
- 코: 작은 삼각 하이라이트 + 한쪽 짧은 음영선. 정면에서도 거의 점 수준.
- 볼: 항상 연한 복숭아 블러시(opacity 25%), 표정에 따라 증감.
- 얼굴 선에 붙는 장식 없음(페이스 페인트 금지). 대신 **왼쪽 눈 아래 작은 시안 회로 점 2개**를 트레이드마크로 한다(토글 가능).

## 4. 헤어 디자인
- 밝은 오렌지(#FF8A1F) 베이스, 끝 쪽으로 따뜻한 노랑(#FFC04D)으로 그라데이션.
- 짧은 중단발~중간 길이(뒤 목덜미를 덮는 정도, 어깨 위).
- 끝부분이 **전류처럼 가볍게 튀는** 곡선-각 조합: 부드러운 S커브로 흐르다가 끝 10%만 짧게 꺾임.
- 번개 모양 지그재그 뭉치 금지(로토무 연상). 꺾임은 "1회 꺾인 붓끝" 정도로 제한.
- 머리 안쪽(이너 컬러)에 시안 브리지 하이라이트 2줄 — 회로 트레이스 느낌의 가는 선.

## 5. 눈 디자인
- 홍채: 금빛/오렌지 방사 그라데이션(위 #C85A00 → 아래 #FFD36B).
- 동공: 세로로 약간 긴 둥근 사각형 + 안쪽 시안 링(얇게, 30% 불투명).
- 하이라이트: 큰 흰색 1개(좌상), 작은 시안 점 1개(우하).
- 오버클럭: 동공이 **이중 시안 링**으로 교체, 홍채 발광. 로토무 눈 구조(파란 오라 속 흰 눈)와 반대로 **눈 자체는 인간형 유지**.

## 6. 테크웨어 의상
- 크림화이트 쉘 재킷(오버사이즈, 하이넥), 오렌지 패널 절개, 검정 이너와 하의.
- 기능 디테일은 **지퍼 1개, 스트랩 2개, 패치 1개**로 제한(가독성 우선).
- 시안 발광 라인은 솔기를 따라 3곳만: 재킷 전면 지퍼 옆, 소매 끝, 후드 가장자리.

## 7. 선화
| 대상 | 굵기(4000px 캔버스 기준) | 색 |
|---|---|---|
| 외곽선 | 6~8px, 입·끝 부분 강약 | 진한 갈색 #3A2418(피부), #1A1A1F(의상) |
| 내부선 | 3~4px | 동일 계열, 70% |
| 머리 선 | 4~6px | #8A3A00 (오렌지 계열 컬러 트레이스) |
| 발광 파츠 | 선 없음 또는 2px 시안 | 발광 느낌 유지 |
- 선은 깔끔하고 끊김 없음. 겹침 부위는 파츠별 분리를 위해 **각 파츠에 선을 포함**해 그린다.

## 8. 채색·명암
- 3단계: 베이스 / 1차 그림자(셀, 선명한 경계) / 2차 깊은 그림자(좁게). 하이라이트 1단.
- 광원: 좌상단 주광 + **코어·케이블에서 나오는 시안 반사광(림 라이트)**.
- 그림자 색은 채도 있는 보라~적갈색 계열(회색 금지): 피부 #E8A48C, 크림 #D9C9B8, 오렌지 #D95F10.

## 9. 피부
- 베이스 #FCE6D6, 1차 그림자 #EFB9A0, 블러시 #FF9C8A(25%).
- 광택 하이라이트 없음(코끝·입술 제외 매트).

## 10. 머리카락 광택
- 앤젤링 하이라이트를 **회로 패턴 형태**(끊긴 직선+점)로 — 로티움 고유 요소.
- 색: #FFF1C9, 오버클럭 시 #BFFBFF로 교체.

## 11. 재질 구분
| 재질 | 사용처 | 표현 |
|---|---|---|
| 천(쉘) | 재킷 | 넓은 셀 그림자, 주름 적게, 하이라이트 없음 |
| 천(니트/이너) | 이너, 목 | 부드러운 그림자, 세로 리브 선 약간 |
| 무광 플라스틱 | 헤드셋, 코어 케이스 | 두꺼운 그림자 + 모서리 하이라이트 한 줄 |
| 금속 | 지퍼, 플러그 단자 | 고대비, 날카로운 흰 하이라이트 |
| 홀로그램 | UI, 드론 링 | 반투명(60%), 스캔라인, 가산(Add) 블렌딩 |
| 발광 | 코어, 라인, 전기띠 | 흰 코어 → 시안 → 투명 그라데이션, 외부 글로우 레이어 분리 |

## 12. 작은 크기 가독성
- 256px 썸네일에서 식별 요소 3개: **오렌지 튀는 머리, 크림 하이넥 재킷, 가슴 시안 코어**.
- 헤드셋 오렌지 이어컵은 머리색과 구분되게 **검정 바디 + 시안 링**.
- 흑백 변환 테스트: 머리(중간 명도)/재킷(밝음)/이너(어두움) 3단 분리가 유지되어야 함.

## 13. Live2D 분리 친화 구조
- 겹침이 적은 레이어드: 앞머리 ↔ 눈썹 사이 여유, 재킷 칼라 ↔ 턱 사이 여유.
- 소매는 팔과 분리 가능하도록 넉넉한 원통형.
- 장식은 몸에 "달려 있는" 형태(스트랩·체인)가 아니라 "떠 있는" 형태(드론·UI)를 우선 → 리깅 간섭 최소.
