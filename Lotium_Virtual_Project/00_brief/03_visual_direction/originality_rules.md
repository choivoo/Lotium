# 03-3. 오리지널리티 규칙 (로토무 직복제 방지)

로티움은 "가전에 깃드는 전기 존재"라는 **일반적 아이디어**만 공유한다. 표현(형태·문양·구조)은 전부 독자적이어야 한다.

## 1. 절대 금지 (직접 복제 금지 목록)
| # | 금지 대상 | 구체적 금지 내용 |
|---|---|---|
| 1 | 공식 얼굴 | 둥근 몸체에 얼굴이 붙은 구조, 오라 속 눈 배치 |
| 2 | 공식 눈 | 파란 오라/테두리 안의 흰 타원 눈, 동공 없는 흰 눈 |
| 3 | 공식 입 | 몸체 하단의 반원형 큰 입, 이빨 없는 D자 입 |
| 4 | 몸 실루엣 | 구형/타원형 몸통, 몸 주위 오라 윤곽 |
| 5 | 번개형 팔 구조 | 몸에서 떨어져 떠 있는 번개 모양 돌기·팔, 지그재그 부속 |
| 6 | 공식 폼 디자인 | 전자레인지/세탁기/냉장고/선풍기/잔디깎이 기반 폼, 그 색 조합·형태 |
| 7 | 몬스터볼 | 상하 2색 구체+가운데 띠+버튼 형태 전체 (코어·드론·버튼에 사용 금지) |
| 8 | 포켓몬 UI | 게임 HP바 디자인, 배틀 텍스트박스, 도감 UI, 공식 폰트 |
| 9 | 공식 로고·심볼 | Pokémon 로고, 타입 아이콘(전기 타입 문양 포함), 번개 타입 배지 |
| 10 | 이름/대사 | "Rotom", 울음소리 흉내, 공식 대사 인용 |

## 2. 경계 요소 (사용 시 변형 필수)
- **주황+파랑 전기 조합**: 파랑 대신 시안(#3FF2FF), 오라가 아닌 라인 발광으로만.
- **번개 모양**: 번개 볼트 아이콘 대신 회로 트레이스(직선+직각+점), 파형(사인파), 신호 막대.
- **떠 있는 부속**: 몸에 붙은 돌기가 아닌 분리된 드론·UI 패널로.
- **기기 폼 체인지**: 가전 대신 방송/모바일/게임 등 "사용 환경" 기반 폼.

## 3. 사용 가능 모티브
전기 / 전자기기 / 기기 접속 / 디지털 생명체 / 폼 변화 / 장난스러움
→ 표현 수단: 회로 패턴, 케이블·플러그, 배터리 게이지, 신호 막대, 홀로그램 UI, 스캔라인, glitch, 코어 발광, 헤드셋.

## 4. 변형 원칙
1. **인간형 우선**: 정령성은 이펙트·소품에만, 몸과 얼굴은 완전한 인간형 애니 캐릭터.
2. **독자 시그니처 3개**: 회로형 앤젤링, 마름모 코어, 케이블 꼬리+캡슐 드론 "핍".
3. **형태 언어**: 둥근 모서리 사각/마름모/끊긴 호 — 구체·지그재그 배제.
4. **배색 비율**: 크림 40 / 오렌지 30 / 검정 20 / 시안 10. 주황 단색 몸체 인상 금지.
5. **이름 거리두기**: 공식 명칭을 레이어명·파일명·프롬프트에 쓰지 않음(프롬프트 네거티브 제외).

## 5. 검수 질문
- 캐릭터 이름을 가리고 봤을 때 "로토무 인간화"라는 말이 먼저 나오는가? → 나오면 실패.
- 구, 흰 오라 눈, 번개 돌기 중 하나라도 있는가? → 제거.
- 레퍼런스 이미지를 트레이싱/부분 합성했는가? → 금지, 재작업.
