# 03-2. 실루엣 규칙

## 1. 원거리 식별 실루엣
- 기본 형태: **"튀는 머리 + 넓은 A라인 재킷 + 가는 다리 + 뒤로 흐르는 케이블 꼬리"**.
- 머리-몸 비율 대비: 머리 볼륨이 크고, 재킷이 허벅지 중간까지 벌어져 상단이 무거운 역방향 안정감.
- 검은 실루엣 테스트에서 3요소 읽힘: ① 머리 끝 4~5개의 튀는 가닥 ② 하이넥 칼라+헤드셋 돌출 ③ 한쪽 뒤로 곡선을 그리는 케이블.

## 2. 헤어 외곽선
- 윗머리: 둥근 돔 위에 뒤쪽으로 흐르는 가닥 3개(대칭 금지, 왼쪽 2·오른쪽 1).
- 옆머리: 볼선에서 바깥으로 살짝 튀며 끝남.
- 뒷머리: 목덜미 덮는 층 2단, 끝이 바깥쪽으로 짧게 꺾임.
- ahoge: 1가닥, 완만한 S자 → 끝만 1회 꺾임. **Z자 번개형 금지.**
- 외곽 꺾임 각도는 120° 이상(날카로운 60° 지그재그 금지).

## 3. 재킷 실루엣
- 하이넥 칼라가 턱 아래까지 올라와 얼굴 하단을 프레이밍.
- 어깨 드롭 숄더 → 소매가 손목에서 넓어지는 벨 형태(손을 반쯤 덮음).
- 밑단은 앞 짧게/뒤 길게(뒤는 허벅지 중간), 옆 슬릿.
- 후드는 등 뒤에 접혀 있음(토글 시 머리 위로).

## 4. 케이블/전기띠
- 허리 뒤 코어 포트에서 1가닥, 좌측 뒤로 S커브를 그리며 발목 높이까지.
- 끝은 플러그 단자(사각형 2핀 계열, 실제 규격 형태를 단순화). 번개 모양 끝 금지.
- 주변에 얇은 시안 전기띠(반투명) 1~2줄이 나선형으로 감김 — 물리 흔들림 담당.

## 5. 헤드셋
- 한쪽(왼쪽)만 붐 마이크. 이어컵은 둥근 사각형, 머리 외곽선 밖으로 약 10% 돌출.
- 헤드밴드는 머리카락 **위**로 지나가 실루엣에 한 줄 선을 만듦.

## 6. 코어
- 가슴 중앙 약간 아래, 재킷 지퍼 라인 위. 육각형이 아닌 **둥근 모서리 마름모**(4각 로젠지) + 시안 발광.
- 실루엣상 드러나지 않지만 명도 대비 최고점 → 시선 집중.

## 7. 드론/정령 장식
- 오른쪽 어깨 위 떠 있는 소형 드론 1기("핍"): 공 형태 X, **납작한 캡슐+이어컵 닮은 귀 모양 안테나 2개**.
- 머리 뒤 반투명 정령 링 1개(원이 아닌 끊긴 3분할 호).
- 드론은 몸 외곽에서 최소 머리 0.3개 이상 떨어뜨려 실루엣을 분리.

## 8. 기본폼 vs 오버클럭폼
| 항목 | 기본폼 | 오버클럭폼 |
|---|---|---|
| 머리 | 튀는 가닥 4~5개, 중력 따름 | 가닥이 위로 들림, 끝에 시안 스파크, 외곽 +10% |
| 재킷 | 닫힘, 밑단 내려감 | 밑단·후드 끈이 위로 뜸(에너지 상승) |
| 케이블 | 아래로 늘어진 S커브 | 공중에 떠서 큰 C커브, 전기띠 3줄 |
| 링 | 3분할 호 1개 | 2중 링 + 회전 |
| 드론 | 1기 | 1기 + 발광 트레일 |
| 전체 | 안정된 역삼각 | 위로 퍼지는 불꽃형 |
