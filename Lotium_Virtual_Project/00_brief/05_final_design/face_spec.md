# 얼굴 사양

## 얼굴형
- 부드러운 V라인, 턱끝 둥글게. 볼 곡선은 B안 대비 +5%(친근함).
- 얼굴 폭:높이 = 1 : 1.15.

## 눈
| 요소 | 사양 |
|---|---|
| 크기 | 얼굴 폭의 23% |
| 형태 | 위 라인 완만한 아치, 눈꼬리 수평~살짝 올라감 |
| 속눈썹 | 위 라인 굵게 + 눈꼬리 짧은 가닥 2. 아래 속눈썹 없음(얇은 아래 라인만) |
| 흰자 | #FFFFFF, 위쪽 속눈썹 그림자 #E6E0F0 |
| 홍채 | #C85A00 → #FFD36B 방사, 테두리 #7A3000 |
| 동공 | 세로로 약간 긴 둥근 사각, #3A1400 + 안쪽 얇은 시안 링 30% |
| 하이라이트 | 큰 흰(좌상) + 작은 흰(우상) + 시안 점(우하) |
| 오버클럭 | 동공 → 이중 시안 링, 홍채 발광(Add), 눈 주변 스파크 |

## 눈썹
- 가늘고 곧게, 끝만 살짝 아래로. 색 #C85A00. 앞머리 사이로 보이도록 높이 조정(가려져도 전체 그려서 분리).

## 코
- 코끝 작은 하이라이트 + 오른쪽 짧은 음영선.

## 입
- 기본: 작은 열린 미소(ω 아님), 선 하나 + 입 안 작은 면.
- 입 안 #7A2E2E, 혀 #E86A6A, 윗니 한 줄 흰색(송곳니 없음).
- 립색 없음.

## 귀
- 반쯤 노출, 둥글고 작음. 왼쪽 귀 연골에 검정+시안 이어커프.

## 블러시·특징
- 블러시 #FF9C8A 25%, 가로 사선 해칭 3줄(옵션 레이어).
- 왼쪽 눈 아래 시안 회로 점 2개(Face_Mark, 토글).

## 인상 키워드
호기심 / 밝음 / 중성 / 장난기. 여성적 요소(립, 긴 속눈썹)와 성인 남성 요소(각진 턱, 목울대) 모두 배제.
