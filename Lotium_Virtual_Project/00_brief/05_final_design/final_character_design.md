# 05. 최종 캐릭터 디자인 — Lotium / 로티움 (확정)

## 정체
전자기기와 네트워크를 돌아다니며, 방송 시 인간형 아바타를 출력하는 **무성 디지털 전기 정령**.

## 핵심 사양 요약
| 항목 | 확정 내용 |
|---|---|
| 체형 | 슬림한 소년형~중성형, 6.5등신 |
| 나이 인상 | 15~17세 |
| 헤어 | 밝은 오렌지 중단발, 끝 10%만 전류처럼 가볍게 꺾임, 회로형 앤젤링, 시안 이너 브리지 |
| 눈 | 금빛/오렌지 홍채, 둥근 사각 동공 + 얇은 시안 링, 하이라이트 3 |
| 의상 | 크림 쉘 하이넥 테크웨어 재킷 + 오렌지 패널, 검정 이너/카고 팬츠, 테크 스니커 |
| 발광 | 시안 — 코어, 소매 끝, 헤드셋 링, 케이블 전기띠, 머리 이너 라인 |
| 액세서리 | 슬림 헤드셋(왼쪽 붐 마이크), 마름모 에너지 코어+게이지 링, 허리 뒤 케이블 꼬리, 캡슐 드론 "핍", 3분할 정령 링, 홀로 UI 패널 2 |
| 시그니처 | 회로형 앤젤링 / 마름모 코어 / 케이블 꼬리+핍 / 왼눈 아래 시안 점 2 |
| 배색 비율 | 크림 40 / 오렌지 30 / 검정 20 / 시안 10 |

## 폼 확장
| 폼 | 추가/변경 (토글) |
|---|---|
| 기본 방송폼 | 기준 |
| 모바일폼 | 헤드셋 → 이어피스, 스마트폰 프레임형 UI 패널, 배터리 아이콘 드론 표시 |
| 게임폼 | 시안 HUD 바이저, 손등 LED 강, 콤보/배터리 HUD |
| 오버클럭폼 | 머리 들림+스파크, 눈 이중 시안 링, 코어 백열, 케이블 부유, 2중 링, 경고 UI, 전신 림라이트 |

## 디자인 원칙
1. 디테일은 상반신 집중, 하반신은 단순.
2. 모든 장식은 리깅 가능한 단위로 분리되고 토글 가능해야 한다.
3. 로토무 구조(구체·오라 눈·번개 돌기)는 어떤 폼에서도 쓰지 않는다.
