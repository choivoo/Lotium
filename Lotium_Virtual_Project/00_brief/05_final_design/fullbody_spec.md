# 전신 사양

## 비율 (머리 1 = 1등신, 총 6.5)
| 구간 | 위치 |
|---|---|
| 머리 끝 ~ 턱 | 0 ~ 1.0 |
| 어깨선 | 1.35 |
| 코어 | 1.9 |
| 허리(재킷 스트랩) | 2.6 |
| 앞 밑단 / 뒤 밑단 | 3.1 / 3.7 |
| 무릎 | 4.6 |
| 발바닥 | 6.5 |
- 어깨 폭 = 머리 폭 × 1.6, 골반 폭 < 어깨 폭.

## 기본 포즈 (원화)
- 정면, 대칭 A포즈(팔 몸에서 15° 벌림), 손 펴서 약간 안쪽, 발 어깨 너비의 70%.
- 케이블 꼬리는 좌측 뒤로 보이게, 드론은 우측 어깨 위.

## 부위별
| 부위 | 사양 |
|---|---|
| 목 | 가늘고 곧게, 목울대 없음. 하이넥 칼라 사이로 1/3 노출, 검정 케이블 초커 |
| 몸통 | 평평, 굴곡 없음. 재킷 볼륨으로 형태 결정 |
| 팔 | 가늘고 곧게, 팔꿈치 각진 표현 없음. 상완/전완 분리 |
| 손 | 가늘고 긴 손가락, 손톱 표시 최소. 오른손 검정 핑거리스 장갑+손등 LED |
| 하의 | 검정 테이퍼드 카고, 무릎 약간 여유, 오렌지 스트랩 1(왼 허벅지) |
| 다리 | 곧고 가늘게, 발목 노출 없음 |
| 신발 | 크림 테크 스니커, 검정 두꺼운 솔, 오렌지 끈, 뒤꿈치 시안 LED 탭 |

## 가려진 부위 복원 필요
재킷 안 몸통/이너 전체, 소매 안 팔, 앞머리 아래 이마·눈썹, 헤드셋 아래 머리, 칼라 아래 목, 머리카락 아래 귀, 밑단 아래 허벅지.
