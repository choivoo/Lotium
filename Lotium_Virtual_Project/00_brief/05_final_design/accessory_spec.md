# 액세서리 사양

| 액세서리 | 형태 | 색 | 움직임 | 토글 |
|---|---|---|---|---|
| 헤드셋 | 슬림 밴드(머리 위), 둥근 사각 이어컵, 왼쪽 붐 마이크 | 검정 + 이어컵 시안 링, 밴드 안쪽 크림 | 머리 추종, 마이크 약한 흔들림 | on/off |
| 이어피스(모바일폼) | 왼쪽 귀 소형, 시안 LED | 검정/시안 | 머리 추종 | 모바일폼 |
| 에너지 코어 | 둥근 모서리 마름모, 케이스 + 발광면 + 게이지 링 | 검정 케이스, 시안 발광 | 호흡 연동 맥동, 게이지 회전 | 발광 약/중/강 |
| 케이블 꼬리 | 허리 뒤 포트 → 좌측 뒤 S커브, 끝 2핀 플러그 | 검정 케이블, 은색 핀 | 3~5마디 물리 | 오버클럭 부유 |
| 전기띠 | 케이블 감는 반투명 나선 1~2줄 | 시안 + Add | 흐름 애니 | 강도 |
| 드론 "핍" | 납작 캡슐 + 귀형 안테나 2, 눈 LED 2점 | 크림 바디, 오렌지 안테나, 시안 눈 | 부유(상하), 따라오기 | on/off, 표정 연동 |
| 정령 링 | 머리 뒤 3분할 끊긴 호 | 시안 홀로 | 느린 회전 | on/off, OC 2중 |
| UI 패널 L | 배터리 바 | 시안 홀로, 부족 시 #FF4A3D | 부유 | on/off |
| UI 패널 R | 신호 막대/이모트 | 시안 홀로 | 부유 | on/off |
| 게임 바이저 | 헤드셋에서 내려오는 반투명 바이저 | 시안 40% | 개폐 | 게임폼 |
| 이어커프 | 왼쪽 귀 | 검정+시안 | 없음 | 상시 |
| 얼굴 회로 점 | 왼눈 아래 점 2 | 시안 | 없음 | on/off |

## 제한
- 동시 표시 액세서리 최대 7종(기본폼), 오버클럭 시 9종.
- 드론은 1기만. 추가 드론·무기형 장비 금지.
- 모든 UI 기호는 오리지널(실제 앱/게임 UI 모방 금지).
