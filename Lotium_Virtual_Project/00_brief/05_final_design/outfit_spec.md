# 의상 사양

## 재킷 — 크림 쉘 테크웨어
| 요소 | 사양 |
|---|---|
| 소재 | 무광 쉘(크림 #F6EFE2) |
| 칼라 | 하이넥, 턱 아래까지. 안쪽 오렌지 라이닝 |
| 패널 | 어깨 요크·옆구리 오렌지 패널, 경계 스티치 #D95F10 |
| 지퍼 | 중앙 1개(금속), 지퍼 옆 시안 발광 라인 |
| 밑단 | 앞 짧게(허리 아래 0.5등신)·뒤 길게(허벅지 중간), 옆 슬릿 |
| 후드 | 등 뒤 접힘, 가장자리 시안 라인. 토글로 머리 위 착용 버전 |
| 후드 끈 | 칼라에서 오렌지 끈 2개, 끝 금속 팁 (물리) |
| 스트랩 | 허리 오렌지 스트랩 1 |
| 패치 | 왼팔 상완 신호 막대 모양 패치(오리지널 기호) |
| 등 | 허리 뒤 케이블 포트(검정) |

## 소매
- 드롭 숄더, 손목에서 벨 형태로 넓어져 손등 절반 덮음.
- 끝단 시안 라인, 안쪽 오렌지 라이닝 노출.
- Live2D: 상완/전완/소매끝 분리, 소매 안쪽 면 별도.

## 이너
- 검정 핏 하이넥 이너, 가슴 코어 소켓, 세로 시안 회로 라인 2줄.
- 재킷에 가려지는 부분 전체 복원.

## 장갑
- 오른손 검정 핑거리스, 손등 LED(시안). 토글.

## 하의
- 검정 테이퍼드 카고, 무릎 약간 여유, 포켓 1(왼 허벅지) + 오렌지 스트랩 1.

## 신발
- 크림 테크 스니커, 검정 두꺼운 솔, 오렌지 끈, 뒤꿈치 시안 LED 탭.

## 가공 금지
- 벨트·체인·버클 추가 금지, 문구·로고 금지, 주름 과다 금지.
