# Forbidden Comparison Set — 공식 로토무 (비교 검수 전용)

사용자가 제공한 공식 로토무 이미지 7장(기본, 히트, 워시, 프로스트, 스핀, 커트, 도감 로토무)을 **검수 비교용으로만** 확인했다.
저작권 보호 이미지이므로 **저장소에 저장하지 않으며**, 레퍼런스 보드·이미지 생성 입력(img2img)으로 사용하지 않는다.

## 관찰된 공식 특징 → 로티움에서 금지
| 공식 특징 | 로티움 금지 규칙 |
|---|---|
| 둥근 주황 몸체 + 위로 솟은 뿔 1개 | 정수리 단일 뾰족 뿔/ahoge 금지 — ahoge는 부드러운 S자, 끝 둥근 꺾임 |
| 몸 전체를 감싸는 단색 오라 외곽선(파랑/빨강/보라/노랑/초록) | 캐릭터 외곽 전체 발광 테두리 금지 (OC 림라이트는 가는 선, 시안만) |
| 흰 타원 안에 색 링이 있는 눈 | 흰 테두리 링 눈 금지 — 인간형 애니 눈(흰자+홍채+동공) 유지 |
| 몸에서 떨어진 번개 모양 팔 2개 | 지그재그 부속·팔 모양 전기 금지. 전기띠는 케이블을 감는 나선만 |
| 가전 몸체(전자레인지·세탁기·냉장고·선풍기·잔디깎이) | 가전 모티프 의상·소품 금지 |
| 화면이 몸체인 도감형(빨간 기기 + 화면 얼굴 + 파란 화면) | 화면형 얼굴/가슴 화면 금지, 빨간 기기 몸체 금지 |
| 세탁기 원형 창(시안 원 + 검정 테두리) | 원형 시안 코어 금지 → 마름모 코어 유지 |
| 전기 꼬리(잔디깎이 폼 아래 번개) | 케이블 끝 번개 모양 금지 → 2핀 플러그 |
| 이빨 드러낸 반원 큰 입 | 반원형 큰 입 금지 |

## 허용(아이디어만)
전기 생명체 / 기기 접속 / 디지털 정령 / 폼 변화 / 장난기. 주황+시안은 쓰되 **인간형 테크웨어 배색**으로만.

## QA 사용법
생성 이미지를 이 표와 대조하고, 1개라도 해당하면 FAIL → `03_concepts/images/rejected/`.
