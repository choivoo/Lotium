# Live2D용 PSD 레이어 구조 설계

## 1. 캔버스
- 4000×6000px, 300dpi, RGB 8bit, 배경 투명. 파일명 `LTM_psd_main_vNNN.psd`.
- 레이어는 **래스터 레이어만** (조정 레이어·클리핑·레이어 효과 금지 — Live2D 임포트 전 병합).
- 블렌딩: 발광/홀로 레이어만 Add(선형 닷지) 허용 → Cubism에서 가산 합성으로 재설정.

## 2. 최상위 폴더 (위 = 앞)
```
LTM_Main.psd
├─ 00_GUIDE            (비표시, 출력 제외)
├─ 01_FX_FRONT         전면 이펙트·UI·스파크
├─ 02_OVERCLOCK        오버클럭 전용 추가/대체 파츠
├─ 03_HAIR_FRONT       앞머리·ahoge·잔머리
├─ 04_HEADSET          헤드셋·바이저·이어피스
├─ 05_FACE             얼굴 전체
│   ├─ Brow_L / Brow_R
│   ├─ Eye_L / Eye_R   (흰자, 홍채, 동공, 하이라이트, 윗라인, 아랫라인, 감은눈)
│   ├─ Mouth           (상/하 입술선, 입안, 치아, 혀)
│   ├─ Face_Extra      (블러시, 땀, 눈물, 회로점)
│   └─ Face_Base       (피부, 코, 얼굴그림자)
├─ 06_HAIR_SIDE        옆머리 L/R 앞·뒤층
├─ 07_EARS             귀·이어커프
├─ 08_ARM_R_FRONT      오른팔(앞) 상완/전완/소매/손
├─ 09_BODY_FRONT       코어·지퍼·후드끈·재킷 전면
├─ 10_BODY             재킷몸판·이너·목·하의·다리·신발
├─ 11_ARM_L            왼팔
├─ 12_BACK             후드(접힘)·재킷 뒷판·케이블 꼬리
├─ 13_HAIR_BACK        뒷머리
├─ 14_FX_BACK          정령 링·후광·뒤 전기띠
└─ 15_DRONE            드론 핍 (독립 부유)
```

## 3. 폴더 목적
| 폴더 | 목적 |
|---|---|
| 00_GUIDE | 비율선·중심선·등신 가이드 |
| 01_FX_FRONT | 표정 이모트, UI 패널, 전면 스파크 — 토글 중심 |
| 02_OVERCLOCK | OC on 시 표시/대체되는 레이어 묶음 |
| 03_HAIR_FRONT | 얼굴 위 머리 — 물리 1차 |
| 04_HEADSET | 헤드셋 on/off, 모바일/게임 대체 |
| 05_FACE | 눈·입 변형, 표정 차분 |
| 06~07 | 옆머리/귀 — 각도 XY 시 가려짐 전환 |
| 08~11 | 팔·몸 — 몸 각도 XYZ, 호흡 |
| 12~13 | 뒤 파츠 — 몸 뒤 물리 |
| 14~15 | 링/드론 — 독립 모션 |

## 4. 파츠 분리 원칙
1. 움직임이 다른 것은 분리, 같은 것은 합침(레이어 수 과다 방지).
2. 좌우 파츠는 `_L`/`_R` 분리(캐릭터 기준 좌우).
3. 선화와 채색은 파츠 단위로 병합(선화 별도 레이어는 눈 윗라인 등 변형 큰 곳만).
4. 발광은 본체와 Glow를 분리.
5. 대체 파츠(표정/폼)는 같은 폴더 안에 두고 기본만 표시.

## 5. 가려진 부분 복원 필수
| 부위 | 이유 |
|---|---|
| 이마 전체·눈썹 | 앞머리 흔들림 |
| 흰자 전체(눈꺼풀 아래) | 눈 뜨고 감기, 동공 이동 |
| 입 안쪽 전체 | 입 개폐 |
| 얼굴 측면·귀 | 머리 X 회전 |
| 목 전체(칼라 아래) | 머리 Y/Z 회전 |
| 머리 아래 두피(헤드셋 밑) | 헤드셋 off |
| 뒷머리 안쪽 | 각도 전환 시 노출 |
| 이너 전체(재킷 안) | 몸 회전, 호흡 |
| 소매 안 팔/소매 안쪽 면 | 팔 움직임 |
| 밑단 아래 허벅지 | 재킷 흔들림 |
| 케이블 포트 주변 | 케이블 물리 |

## 6. 리깅 고려 설계
| 파라미터 | 관련 파츠 | 설계 포인트 |
|---|---|---|
| ParamAngleX/Y/Z | 얼굴·머리·헤드셋·귀 | 얼굴 외곽 10% 여유, 옆머리 앞·뒤층 분리 |
| ParamBodyAngleX/Y/Z | 몸·팔·재킷 | 재킷 앞판/뒷판 분리, 목 이음새 여유 |
| ParamBreath | 코어·어깨·재킷 | 코어 발광 맥동 연동 |
| ParamHairFront/Side/Back | 머리 | 가닥 그룹별 분리, 끝 가닥 독립 |
| ParamAhoge | ahoge | 독립 1레이어 |
| ParamCable / Drawstring | 케이블·후드끈 | 3~5마디 메시 |
| ParamDroneFloat | 드론 | 부유·지연 추종 |
| ParamRingRotate | 링 | 3분할 개별 회전 |
| ParamEyeLOpen/ROpen, EyeBallX/Y | 눈 | 윗라인·아랫라인·홍채 분리 |
| ParamMouthOpenY/Form | 입 | 상/하 라인 + 입안 + 치아 + 혀 |
| 토글 파라미터 | 01·02·04·15 | `08_live2d_notes/toggles_hotkeys.md` 참조 |
