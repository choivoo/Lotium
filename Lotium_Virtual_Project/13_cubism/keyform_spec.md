## 몸 (Body X/Y/Z)
BodyAngleX ±10 → 워프 ±18px, 어깨선 3° 기울기 · BodyAngleY ±10 → 흉부 세로 ±1.5% · BodyAngleZ ±10 → 회전 ±4°.
머리 디포머는 몸 디포머의 자식이므로 체감 비율 = 머리 100% : 몸 35%.

## 눈썹
BrowY ±1 → ±14px · BrowAngle ±1 → ±12° (안쪽 끝 기준) · BrowForm ±1 → 가운데 ±5px 휨.
표정 조합: 기쁨(Y+0.4) 슬픔(Angle+1) 화남(Angle-1,Y-0.6) 놀람(Y+1) 곤란(Form-0.6).

## 입
MouthOpenY 0→1 : Inside·Tongue·Teeth_Lower 세로 0.35→1.15, Line_Lower +48px, 턱선은 DFM_FACE에서 +10px만(볼 무너짐 방지).
MouthForm -1 : 입꼬리 -10px (Pout/Mouth_Wavy 교체 구간) · +1 : 입꼬리 +12px, Closed_Smile/Grin.
MouthShape -1(U/O) : 폭 ×0.7 · +1(I/E) : 폭 ×1.15, 세로 ×0.8.
모음 조합: A=Open1·Shape0 · I=Open0.3·Shape+1 · U=Open0.3·Shape-1 · E=Open0.5·Shape+0.6 · O=Open0.7·Shape-0.8.

## 호흡
