# Hotkey Map — VTube Studio

OS/브라우저 예약키와 충돌을 피하려고 **F5(새로고침)·F11(전체화면)·F12(개발자도구)** 는 VTube Studio 창이 포커스일 때만 동작합니다. 방송 중 OBS가 포커스면 대체키 사용.

## 모드 프리셋 (VTS 핫키 여러 동작 묶기)
| 모드 | 설정 |
|---|---|
| 게임 | Headset=1, Pip=1, CoreGlow=0.6, Game=1, ElectricFX=0.7 |
| 모바일 | UI=1, Pip=1, ElectricFX=0.35, Mobile=1, exp_smile |
| 배터리 부족 | LowBattery=1, CoreGlow=0.2, ElectricFX=0.35, Glitch 펄스 0.3초 |
| 글리치 | Glitch=1 → 2초 후 0 (VTS 핫키 'Hold'로 짧게) |
| 오버클럭 | exp_overclock (Overclock=1, CoreGlow=1, ElectricFX=1) |
